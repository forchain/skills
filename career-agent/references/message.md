# Job Message Generation

## Default Output

Default to one short English job message. Formal cover letters, referral notes, and Chinese messages are optional formats.

Use `message` in user-facing labels for job-search communications.

## JD Analysis

Before writing, classify the JD:

- role intent: what the employer is probably trying to hire
- JD quality: clear, template-heavy, overloaded, unclear, or red-flagged
- core requirements: must answer
- supporting signals: useful if strong evidence exists
- template noise: ignore unless the user asks
- risk areas: mention only when they affect positioning

Do not mechanically match every JD bullet. Extract the few signals that likely drive screening.

When JD quality is poor, continue with lower confidence and a narrower message strategy.

## Application Brief

Create a brief before drafting:

```md
## Fit Assessment
- Strong matches:
- Partial matches:
- Weak or missing:
- Recommendation:

## Role Intent

## Primary Positioning

## Supporting Signals

## Evidence To Use

## Gaps / Questions
```

For cross-domain jobs, choose one primary positioning plus supporting signals. Do not average all directions.

## Questioning

Ask one highest-value question at a time when a core requirement is unknown. Use this shape:

```md
## Question

## Why I am Asking

## My Suggested Answer

## Please Confirm Or Correct
```

Give recommended answers for strategy, positioning, and tone. Do not invent facts, dates, metrics, employers, or responsibilities.

## Drafting

Default constraints:

- 120-220 words unless the user asks otherwise.
- One best version only.
- Concrete fit over broad enthusiasm.
- Use confirmed evidence only for factual claims.
- Do not cover every JD bullet.
- If there is a core gap, bridge conservatively or omit it; never fake a match.

The ordinary output should show:

```md
## Brief
Short fit and strategy summary.

## Message
Final draft.

## Notes
Only show verifier warnings, missing facts, or memory update candidates.
```

Full analysis can be expanded on request.
