# Issue 1: Build the `career-agent` Skill Router and Reference Layout

## What to build

Create the `career-agent` skill as a thin natural-language router with progressively disclosed references. The ordinary user path should be `$career-agent <natural language request>`, while subcommands remain optional shortcuts.

## Acceptance criteria

- [ ] The skill has valid frontmatter, metadata, and agent UI metadata.
- [ ] The entrypoint explains core safety rules and workflow without embedding all branch details.
- [ ] Each branch points to exactly the references needed for that branch.
- [ ] The skill uses `message` as the user-facing term for job-search communications.
- [ ] Repository and skill validators pass.
